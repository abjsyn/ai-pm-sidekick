# 📄 Product Deliverables & Specifications (`docs/`)

This directory is reserved exclusively for the Product Manager's generated product artifacts, requirements specifications, and strategic documentation.

## 🎯 Scope & Purpose
Any deliverable produced by AI PM Sidekick skills will be written here:
- **Product Requirements Documents (PRDs)**: Generated via `/create-prd` (Lean, Standard Agile, Enterprise).
- **User Story Backlogs**: Generated via `/create-user-stories` or groomed via `/refine-user-stories`.
- **UI/UX Design Briefs**: Generated via `/create-design-brief`.
- **Idea Validation Reports**: Generated via `/validate-idea`.
- **Technical & API Documentation**: Generated via `/create-documentation`.

## 📁 File Naming Conventions
- PRDs: `<feature-name>_prd.md`
- User Stories: `<feature-name>_user_stories.md`
- Design Briefs: `<feature-name>_design_brief.md`
- Technical Documentation: `<feature-name>_documentation.md`
- Validation Reports: `<feature-name>_idea_validation.md`

> [!NOTE]
> Internal AI PM Sidekick application specs and Command Center UI documentation have been relocated to [`ui/specs/`](../ui/specs/) to prevent context contamination between the Sidekick harness and your product deliverables.
