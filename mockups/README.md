# 🖥️ Product UI Mockups & Prototypes (`mockups/`)

This directory is reserved exclusively for the Product Manager's generated interactive HTML mockups, wireframes, and UI prototypes.

## 🎯 Scope & Purpose
Prototypes created using the `/create-mockup` skill or the PM Command Center UI wizard are stored here:
- **Interactive Single-Page Prototypes**: Self-contained HTML files styled with Tailwind CSS.
- **Clickable Wireframes**: Featuring responsive views, interactive modals, tabs, and form states.
- **Handoff Artifacts**: Ready for designer review or user testing validation.

## 📁 File Naming Conventions
- Interactive Mockups: `<feature-name>.html` (e.g., `checkout-flow.html`, `onboarding-modal.html`)

> [!NOTE]
> Internal AI PM Sidekick application views and Command Center UI templates reside in [`ui/views/`](../ui/views/) and [`ui/stitch/`](../ui/stitch/) to keep your product mockup workspace clean and separate.
